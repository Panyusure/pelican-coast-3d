# 鹈鹕海岸俱乐部 · Pelican Coast

一个**单文件、离线可玩**的 3D 海岸骑行小游戏。骑上单车沿着海岸线出发，迎着海风、追逐落日，一路收集鲜鱼、避开障碍、完成每日任务。

**▶ 在线游玩：<https://panyusure.github.io/pelican-coast-3d/>**

## 特点

- **单文件**：所有 HTML / CSS / JavaScript 与 three.js（r160）全部内联在 `index.html` 里，无任何外部依赖、无网络请求，双击即可离线运行。
- **3D 海岸世界**：海岸线、海风、落日与沿途风景，支持车铃、镜头切换与自由视角。
- **自适应**：桌面端用键盘，移动端自动出现触屏按钮。

## 操作

| 按键 | 作用 |
| --- | --- |
| `←` `→` / `A` `D` | 变道 |
| `W` `S` | 踩快 / 刹车 |
| `Space` | 跳过障碍 |
| `Shift`（按住） | 冲刺 |
| `B` | 按车铃 |
| `C` | 切换镜头 |
| `P` / `Esc` | 暂停 |
| `K` | 保存明信片 |
| `Q` `E` | 自由视角转向 |
| `V` | 视角回正 |

## 本地运行

直接双击 `index.html` 即可；或用任意静态服务器打开：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000/
```
